# 侍从面板布局与名称编辑

| 区域 | 职责 |
| --- | --- |
| 顶部侍从按钮 | 只切换目标侍从；不触发名称编辑 |
| 顶部状态条 | 跟随、待命、巡逻，以及更多里的回家、设家、遣散 |
| 物品 | 装备、背包、背囊、整理；守卫的自动装备入口在侧栏 |
| 档案 | 名称编辑、自主程度、跟随距离、打法、巡逻点、性格 |
| 成长 | 训练、转职、经验、晋升材料、能力解锁路线 |
| 工程（工程师） | 当前工程、施工控制、蓝图、材料和参数；救援与恢复 |
| 战斗（守卫） | 战斗姿态、攻击／停止、保护／解除护卫、救援、恢复、补给概览 |
| 权限 | 授权设置 |
| 快捷 | 已保存指令的执行、编辑、删除、新建；不再复制内置操作面板 |

未转职侍从仍能进入工程页，原有基础施工与恢复入口不会因隐藏职业页而丢失。
快捷指令的动作 ID、参数、服务端检查均保留，已有绑定无需迁移。

名称输入框固定在档案内容区，编辑后按 Enter 或保存提交；Esc／还原恢复服务端名称。
旧标题点击热区已删除，输入时 E/K 不再触发关闭面板。页面刷新保留未提交草稿，
切换目标侍从则丢弃草稿；名称最终以服务端确认后的状态为准。

侧栏在页签下预留 IPN 整理按钮的位置，其下依次放召回、自动装备，避免重叠。

自动检查包含名称草稿与服务端同步、切换目标、防止控件重叠、最小 GUI 尺寸、
IPN 区域、动作目录和旧快捷绑定兼容性。构建使用 Java 21。
自动化检查不替代实机验收：需在客户端检查两名侍从切换、中文／英文输入、
名称保存与重新打开、主副职业页面、滚动和不同 GUI 缩放。
