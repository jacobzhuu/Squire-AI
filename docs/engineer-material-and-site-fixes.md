# 工程开挖与材料阻塞修复

- 清场保留已经符合蓝图的方块，避免把它们先列为开挖目标、随后又作为已建结构禁止开挖。花岗岩等普通岩石继续按原版硬度和采掘工具判断。
- 清场保持从上到下的顺序，可先挖沙、沙砾，再挖下面的岩石。范围外的落沙顶棚、容器、涌水风险、不可破坏和受保护方块仍会阻止开挖；提示包含具体位置和原因。
- 施工前材料检查与实际扣款使用同一份优惠账单。优惠后成本为零的下一步不再要求物资池额外保留一个物品，避免材料全部正确扣除后卡在最后几格。
- `/squire blueprint fulfil` 为暂停工程补料后调用现有入池和继续施工流程；材料已在背包中时同样可入池继续。尚未确认的预览仍需确认开工，未确定结算的工程保持冻结。
- 工程 UI 区分物资池齐备和背包材料齐备但尚未入池。
- 回收通路将可手动开启的木门视为可通行入口。工程师走近后检查交互权限并真实开门，沿门朝向通行；铁门不视为可自动开启。脚手架仍逐格检查稳定性、返回路线、触及距离和归属后回收退款。
- 开工确认按规划顺序在只读虚拟世界中复查开挖。先挖上层沙砾后，下层花岗岩不再因为现实世界尚未执行第一步而被误报为“不安全或受保护”。安全失败与权限保护会分别报告。
- 未来地基支撑在清场规划完成后才加入虚拟世界，避免同一格同时被判定为“需要开挖”和“已规划支撑”。取消或强制取消留下的脚手架可由后续工程正常清理；与新临时通道一致的脚手架可以复用，但不会被当作新工程资产退款。
- 未确认预览若发现未来地基格已被旧工程遗留物占用，会从当前世界状态重新生成场地与通路快照，不沿用已经过时的冲突计划。

旧的已确认工程保留原快照。材料检查和回收修复可在继续工程时生效；被旧版清场规划拒绝的预览需要重新选择或调整位置以重新规划。
