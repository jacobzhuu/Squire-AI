# 守卫贴身自保

守卫现在优先判断自身附近的威胁，再应用怪物种类的武器偏好。掠夺者、卫道士等即使被列为适合远程对付，也不会让守卫在贴身时继续原地拉弓。

- 每 4 tick 检查 3.5 格内可见的敌对生物和正在攻击自己的生物，高低差不超过 2 格；排除侍从和友军。当前目标贴近时直接检查。
- 临时转向身边最近的威胁，取消拉弓并装备背包中的近战武器。没有近战武器时尝试收弓，物品不丢弃、不复制；背包没有收纳空间时仍停止射箭。
- 紧急自保可以覆盖“优先用弓”以及手动锁弓，无须额外等级解锁。职业的弓箭等级限制保持有效。
- 贴身威胁解除后保留 40 tick 的近战窗口，随后恢复原先打法。手动锁定的弓仍在背包时恢复同一把；玩家在这期间重新指定武器或打法时，以新的设置为准。
- 护卫、自主反击、指定攻击共享规则，低血量撤退仍由原来的护卫策略处理。此次不改变伤害、护甲或职业等级数值，也不加入传送脱困。

回归测试：`M25CombatStyleGameTests` 覆盖手动锁弓被围攻时中断、近战窗口、恢复指定弓、无近战武器自保，以及原有打法和等级限制。
