# 工程师自动地基（2026-09-07）

此前 KeepItLevel 的 `solid` 场地标记是开工前置条件，缺一格都要求玩家先准备地基。
原有自动基础只补建筑最低层下一格，且沿用建筑材料。本次把这两类缺失基础
转换为统一 Blueprint 中的付费地形施工目标。

## 默认行为

- 预览时只读采样附近自然地面，按主要材质选择填补材料；无可靠样本时用泥土。
  草方块、菌丝、灰化土和土径按泥土备料，不要求精准采集。其他候选包括石头、
  深板岩、沙、砂砾、黏土等自然地面；不会复制箱子、工作站或库存。
- 保留已有实心地基；缺失位置向下补到实地，不只悬空垫一层。
  单列最多探查/填补 8 格，总填补最多 8192 格，仍受可达性、世界高度和区块加载约束。
- 先完成地基准备，再掘进清理主体障碍物，最后施工与注液，避免先挖坑把侍从困住。
- 水域标记、门洞、地下负空间不会被无条件填平；冲突明确拒绝。
  原有水域仍沿用供水/人工水域设置，本次不擅自改变这些选择。
- UI 显示自动填补数量；预览、材料清单、分批托管、等级损耗、扣料和施工
  使用同一份 CostPlan。地基是永久材料，不作为免费脚手架生成或回收。
- 泥土地基自然长出草或菌丝不会误报施工失败；普通建筑材料仍严格核对。

自动地基只作用于蓝图指定的地基位置及其垂直支撑列，不把整个包围盒变成实心土台，
不无限填海，不突破领地保护，不传送或飞行。特殊容器、受保护方块等仍遵循既有
清理安全规则；不能承诺自动拆除任意障碍物。

## 实现与兼容

`GroundPreparation.prepare` → 展开后的 Blueprint（含地基）→ 通路规划 → CostPlan
→ 场地准备 → 掘进 → 主体施工。采样不挖走周边材料；仍需交付实际材料。
预览期间原本存在的地基被移走，会重新计算缺失地基。确认后几何和材料不再重新采样。

旧的未确认预览可重新选择落点后使用新功能。旧的已确认工程保留原有冻结几何和账单，
不会在续工时扩大施工范围或追加损耗；需要采用新地基方案时取消并重新预览。
工程与蓝图存档版本升为 7，读取旧格式并保留 `.pre-v7.bak`，旧版本模组将拒绝
读取新存档，避免按旧施工顺序跳过新增的地基阶段。回退版本应同时恢复世界备份。
