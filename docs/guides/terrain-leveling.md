# 工程师平整地基

工程师 Lv1～Lv10 都可以使用，所有等级的范围上限相同。无职业侍从和守卫不能使用。

## 使用方法

1. 打开负责施工的工程师面板（看向 32 格内方块或水面时以该位置定位，否则默认使用脚下位置），在工程页选择“平整地基”。
2. 默认预览 7×7 的区域，目标面与看向方块的顶面齐平。通过宽度、长度、高度和东南西北按钮调整；高度每次变化一格。
3. 蓝色粒子表示目标地面，绿色表示填补，橙色表示挖除。关闭面板仍可查看粒子范围；需要重新检查地形时点击“刷新现场预览”。
4. 检查面板显示的挖填数量、自动采样材料和缺料，确认后开始工程。材料来自玩家或这名工程师的真实库存，可分批补充。
5. 缺料时工程暂停，未齐料前不拆不放。补料后点击继续；也可以手动暂停、继续或取消。取消保留已经完成的地形改动，未用物资按原来源退还。

## 平整规则

- 地面以上清理，低处填至目标面；目标地面层统一使用采样材料，树桩、石块等异种材料挖除后补齐；已匹配的材料保留，泥土自然长草仍按同类地基验收。相连树干及其树冠整体清理，选区外的树枝也纳入预览、账单边界及保护检查。
- 填料自动采样附近自然地形，例如草方块折算成泥土。无合适样本时使用泥土；不会挖取周边地形作为免费材料。
- 普通建筑方块和树木也在允许清理范围内。目标面及以下的水允许填筑，自动从水底向上替换成地基，不先抽水。箱子等方块实体、岩浆、不可破坏方块及受保护位置会阻止开工，并提示坐标；目标面以上仍有水时应提高目标面。
- 取消向上、向下 8 格及 8192 格施工量门槛：向上按实际地形最高点清理，向下填至真实承重地面。长宽可调至 128×128，各等级一致；仅保留世界高度、已加载区块和单次 262144 条预览数据的技术边界，超大工程可分片。未挖除的基岩可以作为承重地面。
- 只施工确认范围内的格子，不向外自动搭脚手架或点灯。深坑等位置没有普通可达站位时，会先核验附近安全站位再由智能辅助逐格填筑；找不到安全锚点、缺工具、地基支撑变化或新增箱子等受保护障碍仍会暂停，处理后可继续。普通草木、普通方块变化以及区域内有生物不再阻止开工；实际填补位置有生物时等待其离开。
- 为处理填土位置已有的植被、台阶等障碍，实际阶段顺序是备料、清理、填补、验收。开始清理之前已经预留完整填料，不用预计挖掘掉落抵扣材料。
- 预览不改世界、不扣料。确认时自动更新普通地形变化，仅实际挖填范围超出已预览边界时需要再确认一次；旧面板发来的操作不会改变新的范围。调整大小、位置和高度时直接刷新面板和粒子，不再逐次刷聊天消息，也不再受距玩家 64 格的调整门槛限制。
- 平地不计建筑竣工经验或建造训练奖励；建筑目录的等级和尺寸限制不影响平地功能。

## 存档与实现

平地以 `terrain_level/<width>/<depth>` 标识持久规格，原点记录目标地面方块坐标。确认时冻结挖填清单、目标地面、承重支撑、材料账单；工程保存绑定侍从、四阶段进度和物资来源。重进世界可恢复。

工程和蓝图摆放存档版本升至 8。读取旧存档时分别保留 `.pre-v8.bak`，旧建筑工程的清单与账单不变；旧版模组拒绝写入新版存档。回退版本需要同时恢复相应存档备份。

新增面板请求 `squire_terrain_action` 携带面板 ID、动作 ID 与预览标识；面板状态包附带预览标识。服务端校验所有者、绑定侍从、职业、参数范围与预览是否过期。
