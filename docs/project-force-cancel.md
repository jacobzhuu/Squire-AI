# 强制取消卡住的工程

工程页顶部点击“强制取消工程”，再点击“确认强制取消（不退款）”。
或由工程所有者执行：

```mcfunction
/squire project cancel force
/squire as "工程师名称" project cancel force
```

不要求 OP；只能终止自己的当前工程。指定侍从时会检查工程归属。
指令和 UI 共用服务端逻辑，不要求施工者存活、施工几何完整或平地预览有效。

强制取消立即释放当前工程与对应蓝图占用，停止关联任务和目标，允许创建新工程。
已放置的建筑方块、脚手架和临时通道留在原地。强制取消不进行自动退款或回收；
剩余材料账目、施工进度和 `pendingMutation` 原样保存在 `projects.json`，状态为
`FORCE_CANCELLED`，便于核对，也避免不确定结算造成重复发放物品。

终止决定先持久化，再停止任务。保存失败会明确报错，不谎报成功。
重启时终止记录不再参与几何恢复，也不变回暂停；恢复的关联任务会被取消。
普通取消仍保留原先的撤离、回收和退款流程。

工程存档升级为 schema 9，首次加载旧版本时自动保留 `projects.json.pre-v9.bak`。
此改动不直接修改用户现有世界；更新 JAR 后由玩家选择要强制取消的工程。

自动回归覆盖缺失几何、存档失败、终止后重启、任务隔离、运行中任务停止、
材料账目保留和释放新工程入口。游戏客户端按钮点击仍需实机验收。
